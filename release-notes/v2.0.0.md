# Hold For Final Hand Score v2.0.0

Updated for current Steamodded and Lovely.

## Install
Download `HoldForFinalHandScore-v2.0.0.zip`, extract it, and put the `HoldForFinalHandScore` folder in `%appdata%\Balatro\Mods`.

## Changes
- Rewritten as a folder mod with Steamodded JSON metadata.
- Plasma Deck and Anaglyph Deck effects work again. The deck result is passed through untouched, and the first pause is queued after the deck effect.
- Fixed the softlock on naneinf scores. The flame wait ignores NaN values and gives up after a maximum time.
- Config tab with on/off toggles and pause lengths.
- Chains with other mods that wrap the same functions, such as Cartomancer and CardSleeves.
